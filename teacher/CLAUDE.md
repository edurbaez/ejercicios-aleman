# teacher/

Loaded automatically by Claude Code when files in this directory are read. Split out of the root `CLAUDE.md` (which keeps a one-line index entry per file); keep in sync per the root Maintenance rule.

## Active Files row

| File | Purpose |
|------|---------|
| `teacher/index.html` | Admin/teacher-only class planner at `/teacher/`. Verifies admin role on load (redirects to `/` if not admin). Level selector (pill buttons, `LEVELS` config array) switches between `teacher/clases-a1.js`/`clases-a2.js`/`clases-b1.js`/`clases-b2.js` (all four preloaded via `<script>`, no dynamic import) — `window.TEACHER_CLASES[level]` and `GRAMMAR_DATA[grammarKey]` are re-resolved per selection, persisted as `teacher_level` in localStorage. C1/C2 show as disabled pills (`LEVELS[].available: false`) until their `clases-{nivel}.js`/`plan.js` exist — enabling a level is a one-line change once the data file lands. Per selected level, cross-references rule ids against `GRAMMAR_DATA.{NIVEL}` to show, per week of that level's 30-day `plan.js`, the grammar content for the Tuesday and Thursday class (fixed mapping: martes = day 2 of the week, jueves = day 4 — a student starting the app on Monday reaches Tuesday's class already having studied day 2). Read-only in this phase: no editing UI yet for teacher-added tips/examples beyond what's in `gramatica.html`. No navbar from main apps; teal theme (`#00695C`), same as `kasus.html`. |

| `teacher/tareas.html` | Admin-only worksheet generator at `/teacher/tareas.html` (same admin check/redirect and teal theme as `index.html`; linked from its header "📝 Tareas" and from each class card as `?nivel={level}&rules={ruleIds}`, which preselects those rules in Reformulaciones). Level pills A1–C2 (`teacher_tareas_level` in localStorage). Three toggleable blocks, all read client-side with the anon key (both tables have public SELECT RLS; `oculto` is filtered client-side with `.eq('oculto', false)`): **Leseverstehen** — `reading_texts` rows with `format_version = 2` (picker or 🎲 random) + Teil checkboxes (`TEIL_NOMBRES`, copy of the one in `lectura veloz.html` — keep in sync with `READING_TEILE_SPECS`); `teilUsable()` drops Teile whose "Lücke N"/"Abschnitt N" items have no `[1]` gap text (some older rows) and warns. **Kasus** — every `grammar_practice_exercises` row with `rule_id LIKE 'kasus:{LEVEL}:%'` (C1/C2 → B2 bank, `KASUS_NIVELES` mirrors `kasus.html`'s level config), deduped by `frase`, per-target counts; "✨ Generar con IA" calls `/api/chat` `generate-kasus` once per checked target (max 6), which verifies and stores the set in the shared bank (also served to students in `kasus.html`). **Reformulaciones** — `../reformulaciones-data.json` rules present in `GRAMMAR_DATA[level]` + `REFORMULACIONES_COMBOS[level]` from `../reformulaciones-combos-data.json`. Empty selection = all. Items are picked round-robin across the selected keys (`pickRoundRobin`). "Preparar tarea" freezes the selection in `S.tarea` (emparejar right columns and Kasus options shuffled once) and renders an HTML preview with answers; "PDF alumno" / "PDF con soluciones" render the same selection via `SECCION[tipo].aufgabe/loesung` (German task headings, Spanish instructions as in the banks; answer key on new pages). Nothing is marked as seen (`user_reading_seen` / `user_grammar_practice_seen` untouched). |

## Data

| File | Purpose |
|------|---------|
| `teacher/clases-a1.js` | Class-content mapping for A1: `window.TEACHER_CLASES.a1` — 30 flat day objects (`{ day, semana, focus, ruleIds[], esClaseEnVivo, contenido.reglas[] }`), cross-referencing `PLANS.a1` (`plan.js`) against the 21 rules of `GRAMMAR_DATA.A1` (`grammar-data-a1.js`). Same martes/jueves live-class calendar as B1 (days 2, 4, 9, 11, 16, 18, 23, 25). Internally built from a `RULES` map + `base(id)`/`repaso(id, nota)` helpers (IIFE) instead of literal per-day duplication like `clases-b1.js`, to avoid the same rule's pedagogical content drifting out of sync across the several days that repeat it — `window.TEACHER_CLASES.a1` still resolves to the same flat 30-object array shape `teacher/index.html` expects. Loaded by `teacher/index.html` and selectable from its level pills. |
| `teacher/clases-a2.js` | Class-content mapping for A2: `window.TEACHER_CLASES.a2` — same shape/pattern as `clases-a1.js` (`RULES` map + `base(id)`/`repaso(id, nota)` helpers, 30 flat day objects), cross-referencing `PLANS.a2` (`plan.js`) against the 21 rules of `GRAMMAR_DATA.A2` (`grammar-data-a2.js`, ids `a2-01`…`a2-23` minus the two renumbered to A1). Same live-class calendar as A1/B1 (days 2, 4, 9, 11, 16, 18, 23, 25). Loaded by `teacher/index.html` and selectable from its level pills. |
