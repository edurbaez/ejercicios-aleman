## Reportes: per-exercise context

Reports with `contexto` (migration 023, sent from `kasus.html`'s "⚑ Reportar" button) show the reported item above the message. If `contexto.set_id` is present, a per-row "Ocultar set" / "Mostrar set" button toggles `grammar_practice_exercises.oculto` (`toggleReportedSet()`, uses the admin UPDATE policy from migration 020); hiding also marks the report `resuelto`. `loadReportedSetsState()` fetches the current `oculto` of every referenced set after load. **The reports query selects `contexto`, so migration 023 must be run or the Reportes list fails to load.**
