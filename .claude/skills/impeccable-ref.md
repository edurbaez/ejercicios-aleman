# Impeccable (global skill)

Installed globally at `~/.claude/skills/impeccable/` (127 files: SKILL.md + reference guides + scripts).

Source: https://github.com/pbakaus/impeccable

## Invoke with

```
/impeccable <command>
```

## Key commands

| Command | Purpose |
|---------|---------|
| `/impeccable shape` | Layout and visual structure |
| `/impeccable audit` | Accessibility, performance, responsive check |
| `/impeccable polish` | Final pass before shipping |
| `/impeccable critique` | UX review: hierarchy, clarity, impact |
| `/impeccable colorize` | Color palette and contrast |
| `/impeccable typeset` | Typography refinement |
| `/impeccable animate` | Motion and transitions |
| `/impeccable distill` | Remove complexity that doesn't earn its place |
| `/impeccable doctor` | Detect drift from design intent |
